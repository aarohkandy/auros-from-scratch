The wallpaper press

No photographs. Just numbers, and a press.

AurOS ships no wallpaper images. It draws the wallpaper at your screen’s exact size from a few lines in the theme file, so a new theme never strands an old picture. This page runs that drawing code in your browser. Pick a theme, pull a fresh seed, keep the one you like.

Why draw it

      

        
A picture that is also a recipe.

        

          

            A photograph is the same size forever and the wrong size for most
            screens. A recipe is drawn at whatever size the screen is, weighs a
            few lines of text, and changes with the theme: switch to Sandstone
            and the wallpaper is redrawn in Sandstone’s colours, not left
            behind in Nocturne’s.
          

          

            The code here is a line-by-line port of
            src/common/wall.c. At seed 0 it was checked
            against the C program for every theme and every style, and differs
            from it by at most one step in one colour channel, because C does
            the arithmetic in smaller numbers than JavaScript does.

Colophon

      

        

          Coloured by two AurOS theme files, nocturne.theme and
          sandstone.theme, copied value for value. Set in whatever
          fonts your computer already has. No analytics, no cookies, no
          advertising, and no request to any server but this one. If you press
          the Nocturne/Sandstone switch, this browser remembers the choice in
          its own storage; nothing is sent.
