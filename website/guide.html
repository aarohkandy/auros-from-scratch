Putting AurOS on this computer

Helping you: Their phone:

Windows and your files stay. You can go back to Windows. Keep the charger plugged in the whole time.

  1. Get it

    On this computer, open @AUROS_ADDRESS@ and press Get AurOS.

    If the browser says the file “isn’t commonly downloaded”, that is normal. Edge: … → Keep → Show more → Keep anyway. Chrome: Download suspicious file.

  2. Open the file

    Windows says “Windows protected your PC”. That is normal too. Press More info, then Run anyway. Then Yes when it asks to make changes.

    “Smart App Control blocked an app” instead? The website, step 2, shows how to switch that off.

  3. Pick a look, press Install

    AurOS checks the computer first and says so before changing anything if it can’t go on it.

  4. It restarts once, by itself

    Leave it switched on until AurOS has started.

  5. “Does everything work?”

    Yes, it all works keeps AurOS. No, go back to Windows brings Windows back. Until you press Yes, Windows and your files are kept just as they were.

To start Windows

As the computer switches on, press the menu key (often F12, F9 or Esc; the maker’s logo often says which) and choose Windows Boot Manager.

To remove AurOS

In AurOS: Settings → Put Windows back, then press Remove AurOS and put Windows back twice. Anything saved in AurOS goes with it.
