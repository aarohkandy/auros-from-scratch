AurOS is a free operating system that gives an old Windows PC a second life.

I’m 11 years old. I still work.

In 373 days, on 12 October 2027, Microsoft stops sending me security updates. Not because anything in me broke. Windows 11 won’t install on me: my processor is older than its list allows. AurOS keeps me safe and up to date instead. One download in Windows, one restart, and every file stays put.

Windows stays on my drive the whole time. Don’t like AurOS? It comes back exactly as it was — that’s the part we tested hardest. Want to see? Scroll down: this whole page is my actual hard drive, and you can watch me switch over right here.

How I start, with Secure Boot left on.

My firmware only starts programs signed by someone it trusts. AurOS comes in through that front door. Nobody has to switch the lock off, open a settings screen, or press a key at the right moment.

AurOS never writes to this partition from Linux. The installer leaves one folder here, \EFI\AurOS, written from Windows. Everything else belongs to Windows and to my maker.

When an update brings a new start-up file, AurOS checks it the way my firmware will before using it: who signed it, whether that signature is revoked, whether it would still start everything after it. If my firmware wouldn’t trust it, I keep the one that works.

  1. My firmwarechecks the next file against the keys it trusts
  2. shim, signed by Microsoftchecks the next one against Canonical’s key\EFI\AurOS\shimx64.efi
  3. GRUB, signed by Canonicalshows my menu: AurOS, Windows, Put Windows back\EFI\AurOS\grubx64.efi
  4. Linux, signed by Canonicalthe kernel, with its lockdown on

What I can’t carry across, and why.

Chrome and Edge passwordsLocked to your Windows sign-in. Sign back into the browser and it syncs.
OneDrive files that are online onlyThey live on Microsoft’s servers, not on me. Make them local first, or sign in to OneDrive.
Windows programsThey’re made for Windows. AurOS has its own for the same jobs.
Printer driversLinux brings its own.
Windows Hello PIN or fingerprintSealed to my security chip. Set them up again.
Files on a locked BitLocker driveThe installer switches BitLocker off first, when you press the button.
Kindle and other copy-protected books and musicLicensed to Windows. Download them again.

Ferry prints this list at the end of every run, whether or not it hit each item.

Where AurOS would go.

AurOS lives in space Windows isn’t using. Here’s what I need for that to work:

  • Windows10 or 11, started the modern way (UEFI). Almost every PC from the last ten years is.
  • Free spaceAurOS takes up to 40 GB of the space Windows isn’t using (less on a small drive), and always leaves Windows at least 20 GB free, or 15% of a big drive.
  • InternetA 1.8 GB download, wired or reliable wireless.
  • TimeAbout 10 minutes on a newer computer with a solid-state drive and fast internet; longer on a spinning hard disk or slow internet.
  • Secure BootLeave it on.
Nothing is written here until you press Restart, and nothing before the restart writes here at all. Before then, the installer only reads.

The way back.

Before the installer changes a single byte of Windows, it saves exactly how I started, and keeps that copy in two places.

Until you tell AurOS it works, Windows is kept exactly as it was, and if AurOS ever fails to start, I start Windows by myself. “Put Windows back” is in AurOS’s Settings and in my start-up menu, behind a question whose answer starts at No. It gives Windows all of its drive back and switches me off; switched on again, Windows starts.

The tests do it twice on every build, then check every file in Windows against its fingerprint from before the install. They all match.

Bad sectors I know about.

A drive that hides its bad sectors is lying to you. These are mine: what’s still wrong, and what was wrong and has been fixed.

openbadNot yet tried on a real PC’s drive.

Everything above is simulation plus a real Windows machine running the installer. A spare PC is the next piece of evidence.

openbadWindows will warn you about the download.

The installer isn’t code-signed yet; that takes a company and a certificate. Avast and AVG hold it for a few hours.

openbadNo Firefox in this build.

The machine that builds it can’t reach Mozilla, so it ships GNOME Web instead and says so.

openbadWi-Fi passwords don’t come across yet.

The network names do. You type each password once.

openbadSome PCs are turned away.

Ones that start the old way (BIOS), failing drives, some setups with several drives. Always before anything changes.

openbadAurOS’s own programs don’t update yet.

Ubuntu’s parts do, the kernel and start-up files included.

v4remappedMy start-up menu printed security errors.

Up to 54 lines on every start with Secure Boot on. Gone.

v4remappedA kernel that wouldn’t start meant I never started.

The fallback to the previous kernel didn’t work. It does now, and it’s tested with a broken kernel.

v4remapped“Nothing has been changed”, after Windows was made smaller.

A sentence that was true in a dry run and false there. It says what happened now.

v4remappedUpdates to my start-up files changed nothing.

The packages installed and my drive kept the old files. Fixed, and tested inside a running AurOS.

siteremappedThis website said two restarts and a required USB stick.

It’s one restart, and no stick.
