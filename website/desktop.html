Try it

Click around in AurOS.

A working model of the AurOS desktop, made from its real theme files and the words on its real buttons. It runs inside this page. Nothing is installed, nothing is sent, and the “Put Windows back” button cannot put anything anywhere.

Theme

Shown at 1024×600, the smallest screen AurOS is designed to work on. Keys inside the model: ← → slide between pages, Enter opens, Esc goes back, Tab moves between buttons. On a phone it is small: choose Actual size and slide it around, or turn the phone sideways and use Full screen.

Things to try

  1. Answer the question AurOS asks first

    On its first start AurOS asks whether it works, and does not hurry you: “Right now, switching this computer on still starts Windows. That stays true until you press Yes.” Those are its words, from src/aurshell/welcome.c.

  2. Bring your files across, and read the report

    After Yes, AurOS offers to bring your files across from the Windows part of the disk, which it only reads. Some things cannot come, and it says which, in a report instead of a silence.

  3. Change how it looks

    Settings → How it looks. The six themes above are the six in AurOS; Settings lists four of them, and the other two are a command away (aurora set ember). Each one redraws the wallpaper from its own numbers, so there is no photograph to go stale.

  4. Try to put Windows back

    Settings → Put Windows back. As in the real one, the remove button has to be pressed twice, and the second press only counts if it comes at least a second and a half after the first, so a double-click or a held Enter key cannot do it by accident.

What a theme is

Run aurora set <name> and the wallpaper, bar, terminal, text console and start-up menu are all regenerated from one of these files.

What this is not

      

        

          

            
It is a model

            
AurOS’s shell is a C program that draws every pixel itself and hands the frame to the graphics hardware. This page is HTML pretending to be that. The layout (“Everything in a row”, the one the desktop image ships with), the words, the colours and the wallpapers come from the source; the apps inside are stand-ins.

          

          

            
The screenshots are older than the theme

            
The real screendumps elsewhere on this site were taken before Nocturne was redrawn from teal to brass. This model uses the theme files as they are today, so it is closer to what an install now looks like than those pictures are.
