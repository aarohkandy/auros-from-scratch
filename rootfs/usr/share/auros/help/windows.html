Going back to Windows

Windows is still on this computer, with your files from before. You can use it for a moment, or go back to it for good.

Use Windows for a moment

  1. Press Turn off at the bottom right of the screen, then Start it again.
  2. As the computer starts, a short list appears for a few seconds, with AurOS at the top. Press the ↓ arrow key on the keyboard straight away: the list then waits for you.
  3. Press ↓ until Windows is chosen, then press Enter.

Windows starts as it was. Next time you switch the computer on, AurOS starts again by itself. If the list goes by too quickly, just try again.

In the first days: “Does everything work?”

When AurOS is new, it asks “Does everything work?” each time it starts. Until you press Yes, it all works, Windows and your files are kept just as they were.

To go back, press No, go back to Windows. Anything you saved in AurOS goes with it, so copy what you want to keep onto a memory stick first.

Go back to Windows for good

This removes AurOS, and gives Windows all of its space back.

  1. First, copy anything you saved in AurOS and want to keep onto a memory stick. It is removed with AurOS.
  2. Press Settings at the bottom of the screen, then Put Windows back.
  3. Press Remove AurOS and put Windows back. It asks you to press again, to be sure. Wait a moment and press it again.
  4. The computer restarts by itself. Leave it switched on and plugged in until Windows has started.

If AurOS won’t start at all, use the short list that appears when the computer switches on: choose Windows to use Windows, or Put Windows back (remove AurOS) to remove AurOS. It asks first, and No, keep AurOS is chosen unless you change it.

When you have finished reading, press Close this at the bottom of the screen.
