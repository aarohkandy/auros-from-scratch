# Per-stream state files

Each stream agent writes `<ID>.md` here (only that stream writes its file):
goal, what's done and pushed, what's half-done, the next steps with files
and commands, traps, and how to verify. Trust these over older notes. If a
stream has no file, its brief is in `docs/handoff/STREAMS.md` or
`START-HERE.md` §5 and its progress is in the Progress log of
`docs/handoff/SESSION-2026-10-23.md`.
