## Goal

Scams are the #1 real threat to her. Three parts:

1. **Firefox policy** `rootfs/etc/firefox/policies/policies.json`:
   HTTPS-only, Safe Browsing locked on and not bypassable, dangerous
   downloads blocked, no telemetry, uBlock Origin force-installed from
   addons.mozilla.org, other add-ons only from AMO with her click.
2. **aurshell "Get me out of this page"** (`src/aurshell/guard*.c`, minimal
   hooks): a page can never trap her; Esc / Home always work; beeping can
   be silenced.
3. **Remote-access warning** before AnyDesk / TeamViewer / RustDesk etc.
   are installed from "Get more programs": "Scammers ask people to install
   this. Only continue if YOU called someone you know."
4. Tests for each: `tools/scamtest*`.

## Traps

- On Linux `/etc/firefox/policies/policies.json` WINS over
  `<install>/distribution/policies.json` (forge's tarball route and probably
  Mozilla's .deb write one there with DisableAppUpdate) -- so ours must carry
  `DisableAppUpdate: true` itself (it does).
- Preferences policy only accepts prefs with allowed prefixes
  (`browser.`, `dom.`, `pdfjs.` ...; NOT `full-screen-api.`); others are
  silently dropped. The test checks this against Firefox's own list.
- aurshell already never grants client fullscreen (session.c configures
  every window with fullscreen=0) and client pixels can never cover the
  band (foot.c) -- the guard builds on that, it does not replace it.
- Tests that link foot.c must not start depending on guard.c (tests.yml
  belongs to stream E); keep guard hooks in main.c.
