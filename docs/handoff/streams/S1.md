## Facts already established (from the local older build, `work/forge/desktop/rootfs`)

- Kernel 6.8.0 (noble). Already ON by config: INIT_ON_ALLOC_DEFAULT_ON,
  RANDOMIZE_KSTACK_OFFSET_DEFAULT, BPF_UNPRIV_DEFAULT_OFF (=2), DMESG_RESTRICT,
  PSI, LSM=landlock,lockdown,yama,integrity,apparmor. NOT on: slab_nomerge
  (SLAB_MERGE_DEFAULT=y), vsyscall=none (XONLY), debugfs (ALLOW_ALL),
  PANIC_TIMEOUT=0 (a panic hangs forever).
- Ubuntu sysctl today: kptr_restrict=1, sysrq=176, ptrace_scope=1,
  protected_fifos=1, protected_regular=2, apparmor_restrict_unprivileged_userns=1,
  unprivileged_userns_clone=1 (bubblewrap). `/etc/apparmor.d/flatpak` is an
  unconfined profile with `userns,` — that is how Flatpak's bwrap keeps working
  under the userns restriction. NEVER set user.max_user_namespaces=0 or
  unprivileged_userns_clone=0.
- Not installed: nftables, earlyoom, zram-tools, systemd-oomd, rsyslog, apport.
  Installed + enabled: cups-browsed (BrowseRemoteProtocols dnssd), avahi-daemon
  (+socket), cups (+socket, localhost:631 only), cups-ipp-utils (ippeveprinter!).
- aurshell runs as a SYSTEM service (system.slice/aurshell.service) and forks
  every app into its own cgroup (src/aurshell/run.c). So systemd-oomd would
  kill the WHOLE desktop; use **earlyoom** (per process, `--avoid aurshell`).
  forge already has profile knobs `zram_percent`/`earlyoom_min_free_percent`
  (stage_configure, written only if zram-tools/earlyoom are installed); only
  revive sets them. Plan: set them in desktop.profile + packages_security.
- Kernel cmdline lives in `rootfs/usr/lib/auros/grub.cfg.in` (4 linux lines)
  AND in `rootfs/usr/lib/auros/bootchain` PREVIOUS template (the fallback
  kernel entry). Both must get the options.
- initramfs-tools honours `fsck.repair=yes` (-> `fsck -y`); without it a
  non-preenable error drops the boot to an initramfs shell ("requires a manual fsck").

## Design (what to build; files)

1. `rootfs/etc/sysctl.d/60-auros-hardening.conf`: kptr_restrict=2,
   dmesg_restrict=1, unprivileged_bpf_disabled=1, net.core.bpf_jit_harden=2,
   yama.ptrace_scope=1, kexec_load_disabled=1, fs.protected_symlinks/hardlinks=1,
   fifos/regular=2, suid_dumpable=0, sysrq=176, dev.tty.ldisc_autoload=0,
   vm.unprivileged_userfaultfd=0, kernel.io_uring_disabled=2, net redirects/
   source-route off. `61-auros-reliability.conf`: kernel.panic=10,
   panic_on_oops=0, vm.swappiness=150 + vm.page-cluster=0 (zram).
2. `rootfs/etc/modprobe.d/auros-hardening.conf`: `install X /bin/false` for
   dccp sctp rds tipc n_hdlc ax25 netrom x25 rose decnet econet af_802154 ipx
   appletalk psnap p8023 p8022 can* atm vivid cramfs freevxfs jffs2 hfs ksmbd
   firewire-core (unprivileged socket() autoloads these: CVE-2017-6074 class).
3. `rootfs/etc/nftables.conf`: inet table, input policy drop; lo, established/
   related, ICMPv6 ND/RA/MLD, DHCPv4 (sport 67 dport 68), DHCPv6 (fe80::/10
   sport 547 dport 546), mDNS ANSWERS only (`udp dport 5353 @th,80,1 1`,
   QR bit) for printer search; forward drop. Enable nftables.service in forge.
4. Printing: purge cups-browsed (the CVE-2024-47176 UDP 631 listener); keep
   cups + avahi browsing (GTK print dialog / CUPS temporary queues find Wi-Fi
   printers); avahi `disable-publishing=yes` (forge edits avahi-daemon.conf).
5. cmdline: `init_on_alloc=1 slab_nomerge randomize_kstack_offset=on
   vsyscall=none debugfs=off panic=10 fsck.repair=yes` (NOT init_on_free).
6. Reliability: zram (zram-tools, 50%, zstd), earlyoom (-m 5, avoid aurshell),
   `rootfs/etc/systemd/journald.conf.d/50-auros.conf` (SystemMaxUse=200M,
   SystemKeepFree=1G, RuntimeMaxUse=48M), `auros-dpkg-repair.service` +
   `rootfs/usr/lib/auros/dpkg-repair` (dpkg --configure -a when dpkg was
   interrupted), aurshell crash loop -> safe mode: drop-in
   `rootfs/etc/systemd/system/aurshell.service.d/50-auros-safe-mode.conf` +
   `rootfs/usr/lib/auros/shell-guard` (3 failures in 5 min -> start with
   `--shell /usr/share/auros/shells/rail.shell --conf /etc/auros/shell.conf`,
   i.e. the machine's plain home instead of her own copies; kiosk -> locked).
7. forge: `packages_security` line in profiles/desktop.profile, added to the
   install list in stage_packages; one stage `stage_harden` (new file
   `build/harden`, sourced by forge) run after stage 4; `harden_verify` before
   the squash refuses an image missing any control.
8. Tests: `tools/hardentest.sh` (static, RFS=work/forge/desktop/rootfs; each
   check proven to fail by mutation) and `tools/hardenboottest.sh` (KVM boot of
   the real image: ss allow-list, an inbound TCP probe through QEMU hostfwd
   must NOT reach a listener, /proc/cmdline, sysctls, dccp socket refused,
   aa-exec -p flatpak bwrap works, ippeveprinter queue prints, memory hog
   killed by earlyoom while aurshell survives, 3 SIGSEGVs -> safe mode,
   corrupted dpkg status repaired, boot time + idle RAM). Workflow
   `.github/workflows/harden.yml` (new; `[harden]` / `[harden RUN-ID]` in the
   subject; concurrency; evidence to prerelease `harden-<run_id>`).
   Results + costs -> `docs/security/HARDENING.md`.

## Traps

- Don't edit the shared main checkout; work in a worktree.
- `nft -c -f` needs root/netlink; test locally as root.
- earlyoom `EARLYOOM_ARGS` single quotes are unquoted by systemd ($VAR, EXTRACT_UNQUOTE).
- avahi `disable-publishing=yes` also blocks local services from publishing
  (ippeveprinter must use `-r off` in the test).
- slirp hostfwd accepts the HOST side immediately; the probe must look for a
  banner from the guest listener, not for a successful connect().
